## 📖 Sobre o projeto

Este repositório foi criado com o objetivo de **estudar e documentar Git e GitHub na prática**.

Durante os estudos, serão registrados conceitos importantes, comandos utilizados no dia a dia e exemplos para facilitar a consulta posteriormente.

A ideia é transformar este repositório em uma espécie de **guia pessoal de Git e GitHub**, acompanhando minha evolução desde os conceitos básicos até recursos mais avançados.

---

## 🎯 Objetivos

* 🧠 Aprender os fundamentos do Git
* 💻 Praticar comandos no terminal
* 🌐 Aprender a utilizar o GitHub
* 🔀 Entender branches e merges
* 📌 Aprender a trabalhar com commits
* 🔄 Entender o fluxo `push` e `pull`
* 🧩 Trabalhar com conflitos
* 👥 Aprender conceitos de colaboração
* 📚 Documentar os conhecimentos adquiridos
* 🚀 Desenvolver boas práticas utilizando Git
