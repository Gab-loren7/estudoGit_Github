## Configurações Iniciais GIT

 Dentro do terminal digite:
 - `git config --global --list` : Para saber a lista de configurações no GIT

 - `git config --global user.name "seu nome"` : Para salvar o seu nome de usuário

 - `git config --global user.email "seu email"` : Para salvar o seu email
